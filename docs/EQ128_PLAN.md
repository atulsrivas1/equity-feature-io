## Sink lifetime and guarantees

Store complete immutable canonical result bytes in a per-instance in-memory reservation map. Exact frozen v1 envelope/schema/descriptor/content/count/bounds admission; ordered whole-result writes; no staged read visibility; commit creates original completion receipt atomically within this single caller-owned Python instance. Same-content replay preserves original receipt; different binding under same key conflicts even after abort; new generation preserves old results. Foreign/stale session, partial commit, duplicate ordinal, unknown version, tampered receipt/content and exceeded bound fail explicitly. Verify retained data before returning committed success. Result references identify immutable per-result bytes. Zero results remains distinct from one observed-empty result.

Declare single_writer/transactional within one instance only; no process safety/restart/persistence/power-loss guarantee or invented elapsed retention. Capability versions are exactly 1/efio-json1/efio-key1/efio-content1/0.0.4a4/1/v1; limits100results/1MiBchunk/10MiBtotal/100000cells/100000evidence, positive reservation_retention_ns=1 while caller preserves the instance, no automatic eviction. Trusted local extension code can execute arbitrary actions; redacted framework errors are not sandboxing or proof extension code never logs secrets.
