## Physical schema before implementation

Storage version `efio-parquet1` is independent of frozen logical versions. Constructor receives an explicit caller-owned root directory, destination_scope, immutable logical limits and positive physical/control byte bounds. Configuration is trusted local scalar data; credentials are not needed. Unknown versions, unsupported requested guarantees, foreign destination_scope and impossible bounds fail before namespace creation. Root/source/private paths never enter receipts or diagnostics.

Own only `<root>/.efio-parquet1/`: stable writer lock, per-key reservation/tombstone record, unique attempt directory and manifest-last completion record. Artifact identifiers are destination-relative fixed safe key/attempt/ordinal names, never absolute paths or caller labels. Reject unexpected symlinks/path escape in this owned namespace. Never delete input stores, foreign directories or committed generations. Abort invalidates ownership and preserves tombstones; old staging remains non-visible. Caller owns explicit storage retention/cleanup; this release adds no scheduled cleanup or automatic eviction.

Each complete result writes THREE physical components in ordinal order:

1. `rNNNNNN.result.json`: exact complete canonical encoded bytes, preserving all metadata, structured nested values, full quality/evidence and order. This is the authoritative lossless record; physical identity is its own SHA256/size.
2. `rNNNNNN.cells.parquet`: ordered cell rows with result/column/entity ordinals, namespace/instrument/session, feature/algorithm/dtype/unit/schema, null flag; exact nullable int64/decimal128(38,0)/float64/bool/UTF8 primitive columns; safe canonical binary value for structured cells. Include matched quality status/expected/observed/ordered reasons. Typed primitive columns never rescale values; signed float zero survives by exact readback framing.
3. `rNNNNNN.evidence.parquet`: ordered evidence ordinals plus feature/entity/input/row IDs, exact signed-int64 event/known-at/effective UTCns (nullable where canonical), use/exclusion reason/boundary. Unknown known_at stays null. Empty tables retain explicit schemas.

The JSON component is required rather than inferring metadata or rebuilding a different canonical schema from projections. Readers independently verify both Parquet projections against reconstructed complete canonical records, exact schemas/order/counts/scalars, every physical size/SHA and full logical content/counts/descriptors/key/receipt. Tampered or missing any component is CORRUPTION. No Pandas coercion or unsafe payload deserialization. Zero publication persists its verified receipt with zero component references; one observed-empty result has all THREE components and different logical framing.

Completion manifest has a closed versioned shape binding the encoded envelope and original receipt; receipt references every component. Manifest itself is not a recursively hashed artifact. Validate all staged components before writing completion last. Write/fsync a same-directory temporary control file then replace the single completion file; committed components are immutable. Reader admits only a complete, verified manifest; presence of directories/staging/control records is insufficient. Do not infer atomicity from directory rename.

## Ownership, lifecycle and qualified assumptions

Declare manifest_last visibility and serialized_writer: one exclusive OS-backed writer lock for this backend destination during a whole attempt (nonblocking POSIX flock or Windows msvcrt byte locking). Multiple cooperating processes/instances serialize; contention is BUSY, never shared concurrent writes. Lock remains a stable file, released by normal abort/commit/close or process exit. Do not unlink/replace a locked inode or use PID/elapsed-time leases. Input adapter remains read-only and independent.

Persist first key/content/count reservation before components. Samekey different content/counts conflicts in STAGING/ABORTED/COMMITTED; timestamp/limits-only changes never manufacture a new key. Same-content committed replay verifies components and returns byte-equivalent original receipt with first commit timestamp. Live owned staging returns BUSY. After an abruptly terminated owner releases the OS lock, a new process may obtain exclusive ownership and restart the same content in a NEW attempt; preserve the original reservation/tombstone and ignore old partial files. No portable resumable session offset. Foreign/closed handles and noncontiguous ordinals fail.

Abort before commitment marks ABORTED and releases ownership; idempotent abort remains ABORTED. After verified commitment, abort preserves original receipt. A previsibility failure can be factual retryable; uncertainty around visibility yields COMMIT_UNKNOWN and lookup, never inferred rollback. Factual CORRUPTION remains an error even if a recovery path finds a receipt. Cancellation cannot retract committed results. Lookup exposes ABSENT/STAGING/ABORTED/COMMITTED distinctly and never treats corruption/unavailability as absence.

Retention policy: backend does not evict reservations/tombstones or receipts; declared minimum reservation floor7days applies while the caller preserves its namespace. No test of elapsed7days is invented. Receipt/read retention is caller-owned without backend expiry. Unsupported retention requests fail explicitly. Constructor close/context manager releases any owned uncommitted attempt, never removes accepted generations.

Qualify only native CPython3.12 x64 Windows/Linux local filesystems actually observed in reports. Record exact runtime/OS/filesystem where available. Reject unsupported platform and explicitly exclude network/object stores, distributed/adversarial writers, hostile directory replacement, machine power loss, kernel/filesystem failure and universal fsync durability. Flush/fsync files and supported directory handles where available; document Windows directory-fsync limitation. Actual process termination/restart and tested local manifest visibility support claims; official API documentation alone does not certify a deployment.
