# Massive historical minute-bar API — EQ070

Canonical [story79](https://github.com/atulsrivas1/equity-features/issues/79), component [PR16](https://github.com/atulsrivas1/equity-feature-io/pull/16), [pre-code plan](EQ070_PLAN.md). Implementation in progress. Local owned tests are useful evidence, not actual account/provider qualification or release.

`MassiveProfile` freezes ticker, canonical instrument/session, namespace, source snapshot/revision, `PriceUnit(9,'USD')`, minute-aligned `InputScope`, optional known-at/record-known-at and governed coverage. Its SHA256 enters the acquisition scope and source mapping/input identity. Only historical unadjusted US stock1m BAR is supported. Request population/session/event bounds exactly match profile. Other kinds/endpoints/adjustments/live reject explicitly. No ticker-only identity joins or session/calendar/eligibility inference. The first mapping fixes USD because these stock prices are not converted currencies.

`MassiveHistoricalAdapter(profile, approve=..., credentials=..., cost_upper_micro_usd=None)` defaults unknown-cost denial. Cost0 is a trusted application assertion requiring independently verified free entitlement plus owner scope, not proof from advertising/credits or an automatic billing query. `MassiveFactory` protocol1 registers explicitly through existing SourceRegistry and admits only `{'profile_id': profile.fingerprint}` config. `CredentialProvider.get('MASSIVE_API_KEY')` occurs only after exact-scope/cost/deadline/cancellation admission; construction/import/capabilities/factory validation do not consult credentials. The effective policy/approval deadline also guards credential lookup. Each adapter permits one iteration attempt, including denial/failure. Fresh caller-created instances require separately allocated cumulative authorization/budget; the library does not grant repeated permission.

Prices are parsed from original UTF-8 JSON using Decimal and converted through exact digit/exponent arithmetic, independent of ambient Decimal precision. No binary float parsing, implicit rounding or quantization. Timestamps must be JSON integer milliseconds and multiply exactly1e6 into int64ns. Whole minute boundaries and interval order/coherence are checked, with end=start+60e9ns. Volume must be exactly integral/int64; `n` remains null when absent. **Fractional volume is unsupported**, even though valid source data. Rounded/derived vendor `vw` never becomes exact actual_notional; that field remains null. Null/zero-volume/OHLC policy uses existing canonical validation before any prefix delivery.

Source coverage defaults unknown/incomplete, including observed empty. A complete declaration needs independent population policy and exact observed count; EOF/resultsCount are not correction completeness. Missing-minute bars are not filled. Original known-at stays absent/future unless caller supplies genuine evidence. Every source binding includes raw response digest, immutable profile and chunk selection, preserving source/delivery coverage separately. The [owned factory/pure consumer](../examples/massive_consumer.py) calculates available BAR proxy/volume under explicitly owned complete reconstruction; exact notional remains null and absent original knowledge nulls causal outputs. It injects synthetic bytes and placeholder credentials, never calls Massive.

Verified TLS fixedhost api.massive.com, oneGET, Bearerheader with no key in URL. Explicit adjustedfalse/sortasc/finite base-aggregate limit and integer start/end_ms-1 prevent snapping widening the exact minute-aligned scope. Response ticker/adjustment/status/counts must agree; next_url/cap-reaching/partial/off-grid/out-of-scope records reject. No redirect/retry/pagination/cache/SDK/flatfile/live/upgrade/subscription. Defaults10wire rows/512KiB logicalbody/30seconds; request/approval caps can tighten. JSON depth8/structural/field-count/commas/numericlength≤128 limits reject enlarged payloads before normalization. Safe errors replace provider diagnostics outside handlers without raw cause/context; trusted process/debugger memory remains outside this diagnostic guarantee.

Socket deadline refreshes before network stages and reads, retaining response-owned sockets. Cancellation is cooperative between stages/records/chunks. Failed read partial bytes and failed normalization bodies are charged to the controller. These limits concern logicalbody/rows/cooperative time, not RSS/TLS overhead/preemptive cancellation. Provider error bodies are not read/logged. Injected credentials/approval/cost/transport are trusted controls, not a sandbox.
