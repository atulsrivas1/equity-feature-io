# Local ordinary trade files (EQ071)

Optional experimental `equity-feature-files==0.1.0a0`. [Source/delivery evidence](../EQ071_DELIVERY.md) and canonical80 record live acceptance; this document describes the experimental API. Dependencies are acquisition.a0 and SDK/contracts.a2. Core/contracts0.0.4a4 remain byte and algorithm invariant. See [pre-runtime plan](../EQ071_PLAN.md), [canonical80](https://github.com/atulsrivas1/equity-features/issues/80) and [owned example](../../examples/files_consumer.py).

## Explicit public construction

`FileProfile(format, namespace, source, price_unit, coverage, scope, sha256, schema="normalized-trade-v1", dbn_dataset=None, dbn_identities=(), dbn_annotations=())` is immutable, has opaque repr and performs no file/network access. Source is existing SourceBinding, units existing PriceUnit, coverage existing Coverage, certified range/eligibility existing InputScope. `sha256` is lowercase exact staged-file bytes. The caller supplies financial completeness, rights, ordinary-event eligibility, namespace, currency, sessions, knowledge evidence and immutable revision; existence/checksum is not evidence of market completeness or rights. Auctions are unsupported. Unknown coverage stays unknown.

`LocalFileTradeAdapter(path, profile, *, approve, policy=ReadPolicy(), clock_ns=time.monotonic_ns, cache=None, retain=None)` implements existing HistoricalAdapter. Construction/capabilities/acquisition_scope do not open files or consult credentials. `LocalFileFactory(profile, *, approve, policy, clock_ns, cache, retain)` implements existing ComponentFactory; its only public config key is `path`. Register with existing `SourceRegistry[HistoricalAdapter]`, or pass the direct instance through existing `admit_source`. There is no second registry. Factory credentials are unused. Public repr/errors omit the path and raw exceptions; exceptions from trusted callbacks are redacted outside their handlers, with no cause/context. Caller debug locals and caller-owned identity strings are outside this redaction guarantee.

Only historical ordinary raw TRADE, declared UTCns-int64, exact scaled prices, integer shares, no sampling, schema1 and supplied namespace/unit are supported. Unsupported kind/unit/snapshot/range/raw-policy, schema or optional dependency fails before file open. No live/provider transport, implicit downloads/installation, bar/reference projection, adjusted input, rounding, sorting or calendar inference. URI and UNC syntax is rejected; this is not a sandbox or attestation of mounts, symlinks or cloud placeholders. The trusted caller must explicitly stage owned/licensed local regular files. No provider request or charge is authorized by this adapter.

## Consent and cache

`acquisition_scope(request)` returns existing AcquisitionScope with mode=file, provider=local-file, supplied source ID as dataset, exact schema+format endpoint, expected SHA source revision, complete profile fingerprint mapping revision and full AcquisitionRequest. `approve(scope)` returns existing scoped DownloadApproval or None. Application-provided local-use approval is required before file read; exact scope, expiry, positive finite calls/bytes/output-rows/elapsed and known zero microUSD cost are enforced by shared AcquisitionController. The library cannot infer consent from a path, credentials or selection. The callback is trusted application authorization, not cryptographic proof of a user click.

Cache is disabled unless caller supplies ImmutableCache and `retain(scope)` returns matching RetentionApproval. Full request, immutable bytes, authorization/revision/expiry and complete profile bind cache keys. A permitted cache hit reparses/checks checksum and normalization under current policy; it avoids a new file read and requires no fresh download approval. It grants no new acquisition/rights/knowledge. Changed units/coverage/scope/source/session/eligibility/known-at/identity annotations produce different mapping and result identities even if the caller reuses mapping_version. The filesystem path is excluded, so identical bytes/profiles staged at different paths are equivalent. Permission expiry/TTL/capacity and caller clear/dispose/session-end duties are inherited from [acquisition controls](ACQUISITION_CONTROLS.md). Cache and operation budgets are serial caller-owned, not global billing or thread-safe isolation.

## Schema and local identity

CSV and Parquet have exactly these nine ordered fields: instrument_id, session_id, event_ns, order_key, event_id, eligible, price, size, known_at_ns. CSV is UTF-8 with exact base10 signed int64 strings, no plus/whitespace/scientific/fractional form; eligible is exactly0/1 and empty known_at_ns is explicit null. Parquet fields are string/string/int64/int64/string/bool/int64/int64/int64 (only known-at may contain null); no nested/float/time conversion. Every supplied row is canonically validated before selection. IDs/order/eligible and unknown/future known-at are preserved; acquisition does not drop knowledge failures. Canonical strict ordering and duplicate rejection apply even to unselected rows.

Optional `parquet`/`full` extras pin PyArrow20.0.0. Footer/Thrift metadata bounds, row counts, column types, compression and aggregate uncompressed sizes are checked before decoding bounded batches with threads disabled. Initial support is UNCOMPRESSED only. Invalid metadata/type/compression fails safely. The codec is not an RSS/decompression/native-call preemption guarantee.

Optional `dbn`/`full` extras pin databento-dbn0.70.0. Only uncompressed DBN3, TRADES, no ts_out trailer/auto-upgrade/mixed records is supported; metadata dataset must match explicit dbn_dataset. Price scale must be9, fixed scale1e9, caller-supplied currency. Signed-int64 overflow, undefined price/size and non-TRADE action fail; no float pretty_price conversion. `DBNIdentity(publisher_id, instrument_id, canonical_id)` supplies the finite unique wire pair map. `DBNAnnotation(session_id, eligible, known_at_ns)` supplies exactly one annotation per physical record, including explicit null/future knowledge. Receive/header timestamps, wire identity/sequence and feed flags never manufacture financial knowledge or eligibility.

DBN records use physical one-based row order_key and `dbn:<file SHA>:<one-based row>` event_id. These are local immutable row identities, not provider-global event IDs, correction lineage or a wire-sequence total order. All three formats preserve financial field/order/unit/coverage parity under the explicit supplied mappings; their physical file/event identities need not equal each other. Bounded metadata is decoded once, then fixed48byte TRADES records individually, with exact EOF checked. Header metadata range is not used to manufacture coverage.

Output source mapping_version adds `:profile:<complete profile SHA>`; input_id adds actual file/profile/selected physical index digests. Each chunk has distinct selection identity. Original source coverage is retained; delivery coverage measures selected chunk rows. Selection uses requested IDs/sessions and `[start_ns,end_ns)`, with no ordering repair. Valid zero-row header/schema/metadata yields observed-empty; missing files fail UNAVAILABLE, malformed files fail SCHEMA/UNSUPPORTED, never observed-empty.

## Finite resource boundaries

ReadPolicy defaults: raw16MiB, original100000rows, metadata1MiB, decoded scalar payload32MiB, reads64KiB, Parquet batches1024rows, max delivered batch1024rows, elapsed10seconds. All bounds are explicit positive int64 values; request output rows/batches are independently bounded. Approval can tighten raw/output/elapsed limits. Raw input is read in checked chunks with a one-byte overrun detector; checksum, whole-input canonical ordering/duplicate/coverage/scope checks and output count/batch bounds finish before first publication. Raw immutable bytes and bounded normalized rows coexist in memory; no zero-copy/performance/hard RSS claim is made. Decoded scalar payload counts string UTF-8 bytes and8bytes per other scalar, excluding Python/native object overhead.

Cancellation, monotonic clock and expiry are checked before/between read/decode/output operations. A callback/codec/native file call is cooperative and cannot be preempted; caller must enforce harder process/storage constraints externally. A cancelled prefix has no final complete envelope and cannot certify whole-request completion. Failed bytes are counted by shared AttemptFailure; public errors contain only fixed typed diagnostics.

## Calculation admission

The adapter publishes original source coverage/certified scope, not a newly invented complete population for every slice. To call pure compute_trades directly, provide the complete single entity/session population in one delivered batch with matching config/session/scope/coverage. A chunk or filtered subset cannot be passed as the whole population by rewriting coverage. Future planner admission remains separate. Owned fixture is exact count3, shares6, tick-share notional13000000000, VWAP13/6USD and mean-size2. Reconstruction explicitly permits all three supplied events; causal mode retains unknown/future knowledge and yields all five null values under existing pure policy. No algorithm/version change is required.

Native Windows/Linux wheel/sdist, default/light and full optional installs, repeated archives, external typing, source/archive/main receipts,61 core-file invariance, separate final-head review and current CI remain release gates. Source tests and synthetic codec evidence do not qualify provider access, account terms, exchange redistribution or production market truth. Free qualification downloads are owner approved; all provider downloads/charges remain denied absent explicit scoped user approval.
