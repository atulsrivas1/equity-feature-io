## Frozen arithmetic and concrete API decisions

Elapsed arithmetic uses injected integer monotonic nanoseconds; absolute expiration is in that same caller clock domain, never market timestamps. Reserve conservative cost in integer USD millionths (micro-USD) before every transport attempt, including failures; refund nothing automatically. Cumulative controller ledger is calls, received bytes, declared successful rows and reserved micro-USD. An approval is one trusted controller scope; instantiating multiple controllers requires the caller to allocate distinct budgets. This is not a provider billing meter or protection against a malicious caller. Unknown cost is rejected for every budget; zero admits only an explicit zero upper bound. No remote quote/purchase endpoint is called to discover cost.

AcquisitionScope contains the canonical AcquisitionRequest, explicit provider/dataset/endpoint/mode, source revision and mapping revision. Scope equality includes request ID, selected instruments/sessions/times, source snapshot, units, adjustment/action anchor, availability, sampling and row/batch limits. DownloadApproval contains exactly that scope, opaque authorization_scope, expiry and immutable AcquisitionLimits. Runtime is a serial controller; reentry/concurrent calls reject, not a shared thread-safe global rate governor. A caller injects clock_ns/sleep_ns/cancelled callbacks and CredentialProvider with key name separately. No standard credential env lookup or file read. Transport protocol receives a credential string only for the call and an AttemptBudget of ordinal/absolute deadline/remaining rows/bytes. It returns a Page of immutable bytes and exact row_count, or reports AttemptFailure with a typed error code, nonnegative received bytes and optional nonnegative retry_after_ns. Those reports are trusted transport statements; wrapper counts them and rejects excess. Network SDKs must disable their own retries and account actual received data while streaming.

RetryPolicy specifies max_attempts, initial_backoff_ns, maximum_backoff_ns, and cancellation_poll_ns, all finite positive integers. After failure number k (k starts at1), delay is max(min(initial*2**(k-1),maximum),retry_after). Saturate doubling without giant integer allocation. If required wait is not strictly within remaining elapsed/approval duration, fail LIMIT without sleeping or another attempt. Poll before/after sliced waits. RATE_LIMIT/TRANSPORT retry only for explicit idempotent reads; all other typed codes and untyped failures terminate. For this support package no external automatic reconnect/pagination loop is provided: each explicitly requested page uses the same ledger, finite scope and remaining bounds.

Fixed safe public errors use canonical SourceErrorCode. Raising occurs after leaving the caught exception handler so raw credential-bearing exceptions are not retained through __context__, rather than merely hiding their traceback display with from None. Public controller/approval/cache repr is fixed or opaque; raw credential, request/config/exception text and payloads are never logged. Public receipts contain only safe numeric counters and typed outcome. Tests traverse traceback formatting and exception cause/context, not just str(). Transport/caller code itself remains trusted.

Cache key is the complete scope plus opaque authorization_scope and an explicit page_key, with immutable revision flag. CachePolicy includes finite max_entries/max_bytes/ttl_ns; RetentionApproval binds same scope/auth partition, immutable revision and exact operational expiry. Admission checks retention expiry even on hits; disabled cache returns miss and writes nothing. New entries evict oldest insertion deterministically until both finite bounds hold; replacement is atomic and a too-large item rejects without removing unrelated entries. TTL starts at insertion and expires exactly at deadline. Cache stores owned immutable bytes/row_count only. It never bypasses network consent: reuse is a separate explicitly approved local operation. A cache hit neither consumes nor creates controller transport budgets. Store rows only when their byte data is inside cap; no errors, credentials or live/mutable scope. Process memory overhead/RSS is not covered by byte-data caps.
