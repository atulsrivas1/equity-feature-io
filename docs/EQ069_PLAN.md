## Supported surface and mathematics

Historical direct HTTP `/v0/timeseries.get_range`, uncompressed DBN3, `trades` and `ohlcv-1m` are the first explicitly supported mappings. QUOTE, DAILY, REFERENCE, compressed/direct files, batch job submission and live/replay remain explicit UNSUPPORTED capabilities; no fallback or auto-registration. Historical SDK0.87.0 is a source-inspection/optional qualification candidate, not the network implementation: its high-level get_range downloads the whole compressed response before returning. Use a fixed-host bounded HTTPS transport with no redirects, hidden retries or pagination. DBN codec0.70.0 is already qualified for local files; independently qualify these additional record mappings.

Prices preserve signed coefficients at scale9, currency explicitly supplied; integral shares and unsigned timestamps/volume/sequence must fit canonical int64. No floating conversion, automatic rounding or sorting. Trade action must be T; undefined-price/size sentinels, wrong record types, invalid units, duplicate/order errors and unmapped identities fail. Stable order_key is provider sequence; event_id and input identity bind publisher/instrument/event/sequence plus immutable response digest and mapping profile. Caller supplies exact publisher/instrument -> canonical instrument/session bindings, session bounds, eligible population policy and optional original known-at values. Never infer regular-session eligibility from T or use capture/retrieval time as historical known-at.

SDK source explicitly says trade ranges filter ts_recv; OHLCV ranges filter ts_event. A frozen profile must specify capture bounds separately from canonical event scope and bind both into approval identity. Filter normalized trades by canonical event [start,end), and bars by whole completed [start,end] intervals. Preserve received rows and caller-declared source coverage separately from delivered chunk coverage. Default source coverage is unknown/incomplete; EOF or a record limit does not certify correction-resolved event population. A supplied complete-coverage assertion needs an explicit capture/eligibility provenance policy and exact expected count; mismatches fail. Do not manufacture missing minute bars as zero rows. OHLCV end=start+60e9 ns, known-at remains absent unless supplied; trade_count and actual_notional remain null. Zero-volume bars require null OHLC under the existing canonical policy.

## Consent, transport and privacy

Import, construction, capabilities and factory config validation perform no credential or network access. Per-request approval binds the canonical request and full immutable profile (dataset, numeric symbols, capture bounds, mappings, eligibility/availability/coverage/source revision). Default deny before credential lookup or transport. Unknown/nonzero conservative request cost cannot pass a zero budget. Credentials come only through CredentialProvider after admission; no environment lookup inside calculations or public config. No automatic cost probe, subscription or batch job. A provider cost estimate is not a hard billing ceiling: actual proof must establish the selected zero-cost entitlement and explicit scope before execution. No adapter-local cache initially; shared optional cache cannot create download/retention permission.

Fixed host hist.databento.com, TLS verification, Basic auth header, POST form encoding, explicit dataset/schema/symbols/stype/encoding/compression/start/end/limit. Timestamp parameters are exact integer UNIX nanoseconds without float. Requested limit is finite; a response reaching the cap rejects rather than falsely certifying a full range. Bound body bytes including error/failed reads, metadata bytes, records and elapsed time; check cancellation between reads/decode/chunks. Socket timeouts enforce remaining deadline cooperatively; no hard RSS/preemption claim. Never log keys, raw payloads, response text or URLs. Map status401 authentication,403 entitlement,429 rate limit,404 unavailable, other transport/schema failures to fixed safe SourceError; raw causes/contexts must not escape. No redirects/reconnect or hidden SDK retry.
