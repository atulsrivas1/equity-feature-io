# Massive historical minute bars — EQ070

Experimental optional `equity-feature-massive==0.1.0a0`, Apache-2.0 code; source implementation in progress, no provider qualification or release acceptance. Provider account/data rights and fees are separate. See [pre-code plan](../../docs/EQ070_PLAN.md).

Historical unadjusted US stock one-minute BAR is the initial explicit surface. Exact Decimal price coefficients at scale9USD, exact ms→int64ns, original caller known-at, separate unknown source coverage and observed delivery. Fractional volume is valid provider data but cannot fit canonical integral shares: **unsupported**, never rounded/truncated/replaced. Actual_notional is null despite vendor VWAP, with no invented exact trade witness. Other endpoints/kinds/live are unsupported. Missing minutes are not filled.

`MassiveProfile` freezes ticker→canonical instrument/session, minute-aligned scope, source snapshot and governance. Exact request must match. `MassiveFactory` protocol1 requires explicit registration and onlyprofile_id public configuration. Credentials are injected as `MASSIVE_API_KEY` through a trusted CredentialProvider after scope/cost/time/cancellation admission; construction/import/capabilities do not look up keys. Unknown cost is denied; budget0 requires independently verified free entitlement and explicit owner scope. No SDK, cost probe, upgrade, subscription, retry, pagination, redirect, cache or live operation.

One fixed verified TLS GET, bearerheader with no key in URL, finite record/base count and logical body/time limits. Default10rows/512KiB/30seconds; cap-reaching/next_url/inconsistent count responses fail. Every received record and whole canonical population validates before any delivery. Socket timeout refreshes before stages/reads, retaining response-owned socket; partial failed bytes are charged. Cooperative cancellation is checked between stages/records/chunks; no RSS/preemption/TLS-overhead guarantee. JSON depth/structural/numeric length bounds precede normalization. Public failures are safe codes with no raw diagnostic/cause/context; trusted debugger memory is outside that guarantee.

Each adapter instance permits one attempt, including denial/failure. Fresh instances need separately allocated owner scope and cumulative budget, never more than authorized requests/rows/bytes. The caller-injected cost upper bound/credential provider/transport are trusted controls, not a sandbox. Scope start/end must align to minutes; wire end=end_ms-1 avoids service snapping widening acquisition. Source completeness requires explicit independent policy/count; no EOF claim.
