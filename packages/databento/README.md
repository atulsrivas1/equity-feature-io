# Databento historical adapter — EQ069 implementation in progress

Opt-in `equity-feature-databento==0.1.0a0` maps uncompressed DBN3 ordinary trades and one-minute bars into accepted canonical contracts. This package is not released or provider-qualified. See [pre-code design](../../docs/EQ069_PLAN.md).

The trusted caller supplies immutable dataset, separate capture/event ranges, publisher/instrument mappings, session, eligibility, source snapshot and price unit (integer coefficients at scale 9). The requested instruments, sessions and event range must exactly match this profile; construct a new profile for a different population. Historical trade requests are filtered by capture timestamp upstream and event timestamp locally. EOF never establishes event-population completeness: coverage defaults to unknown. Explicit complete coverage requires a separately identified policy and exact observed count. One-minute bars preserve null trade count and actual notional; no synthesized VWAP.

Construction, capabilities, factory validation and imports do not read credentials or acquire data. A scope-matched unexpired `DownloadApproval` and independently established exact upper cost are required before credential lookup. Unknown cost is denied, including when a provider advertises credits. `$0` approval admits only a verified zero-cost request. Credential injection uses `CredentialProvider` with `DATABENTO_API_KEY`; never put secrets in configuration or source control.

The fixed TLS endpoint makes one POST with explicit numeric symbols, schema, integer nanosecond bounds, DBN encoding, no compression, finite record limit and no redirects, pagination, retry, cache, batch jobs or live stream. Default caps: 10 wire records, 512 KiB response, 64 KiB metadata, 30 seconds; request/approval limits can lower them. A response reaching its record cap is rejected as potentially truncated. All records are decoded and canonical validation succeeds before delivery. Cancellation and deadline checks are cooperative between reads/records/batches; socket timeout bounds blocking I/O. Limits cover logical response bytes/decoded rows, not total process RSS or HTTP/TLS overhead.

Each adapter is single use, including denied or failed attempts. A fresh instance needs a fresh caller authorization/budget allocation; the library does not coordinate budgets across distinct caller-created adapters. The injected transport and credential provider are trusted extensions, not a sandbox. Public error messages, context and cause omit provider diagnostics. An attached debugger can still access trusted process memory.

The DBN codec is pinned to `databento-dbn==0.70.0`. The inspected upstream Python SDK is not used for network acquisition because its automatic complete-response buffering conflicts with transport byte limits. No numerical dependency or calculation package changes.
